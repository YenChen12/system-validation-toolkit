## 💪 Standardized operations for Vim environments

### <u>Getting Started</u>
>💡 Note:  
    - Press **Esc** to return to **Normal Mode**.  
    - All commands starting with **:** require **pressing Enter to execute**.

1. Insert
    - `i` Insert before the cursor
    - `a` Insert after the cursor
2. Delete
    - `x` Delete the character under the curso
    - `dd` Delete entire line
    - `D` Delete from cursor to end of line
3. Navigation
    - `0` Move to the beginning of the line
    - `$` Move to the end of the line
    - `gg` Move to the first line
    - `G` Move to the last line
    - `h` Move left
    - `j` Move down
    - `k` Move up
    - `l` Move right
4. Scrolling
    - `Ctrl + f` Scroll down full page
    - `Ctrl + b` Scroll up full page
    - `Ctrl + d` Scroll down half page
    - `Ctrl + u` Scroll up half page
5. Search
    - `/keyword` Search for a keyword **[press Enter to execute]**
    - `n` Jump to the next result 
    - `N` Jump to the previous result
    - `:noh` Cancel search highlight
6. Save
    - `:w` Save the file
    - `:w!` Force save the file
7. Quit
    - `:q` Quit (only if no changes were made)
    - `:q!` Force quit and discard all changes
    - `:wq` Save and quit
